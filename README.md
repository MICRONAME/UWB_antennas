# Использование UWB-антенн для точного позиционирования трамвайных вагонов

Репозиторий содержит исходный текст научной статьи, посвящённой применению сверхширокополосной технологии (Ultra-Wideband, UWB) для позиционирования трамвайных вагонов в условиях, где сигналы глобальных навигационных спутниковых систем (ГНСС) недоступны или работают нестабильно.

## Цель работы

Рассмотреть возможность использования UWB-системы для определения координат трамвайного вагона на участках с плотной городской застройкой и в тоннелях, а также определить подход к размещению UWB-антенн с учётом влияния металлического кузова вагона и контактной сети.

## Содержание статьи

В статье рассматриваются следующие вопросы:

1. **Введение.** Обосновывается актуальность высокоточного позиционирования городского электротранспорта и рассматриваются ограничения ГНСС в условиях городской застройки и на подземных участках.
2. **Анализ существующих решений.** Рассматриваются подходы к локализации на основе UWB, гибридных UWB/GPS-систем и визуально-геоинформационных методов. Формулируется проблема, связанная с экранированием и переотражением радиосигнала металлическим кузовом трамвая.
3. **Постановка задачи.** Определяется цель исследования и основные требования к системе позиционирования.
4. **Описание предлагаемого метода.** Рассматриваются методы измерения расстояний ToF (Time of Flight) и TDoA (Time Difference of Arrival), подходы к размещению нескольких антенн на вагоне, электромагнитное моделирование и методика будущей проверки точности.
5. **Список литературы.** Приводятся научные публикации, использованные при подготовке статьи.

Экспериментальный раздел и заключение в текущей версии не представлены, поскольку по условиям задания эти разделы не являются обязательными. Описанная методика испытаний является планом проверки предлагаемого подхода, а не отчётом о завершённых натурных экспериментах.

## Предлагаемый подход

В статье рассматривается позиционирование вагона с использованием UWB-измерений и стационарных опорных узлов (anchors), размещённых вдоль трамвайного пути. Основное внимание уделяется:

- использованию методов ToF и TDoA для получения дальномерных данных;
- размещению нескольких антенн на разных участках корпуса вагона;
- анализу влияния металлических элементов кузова и контактной сети на распространение радиосигнала;
- предварительному электромагнитному моделированию и последующему сравнению рассчитанных координат с данными референсной системы.

## Сборка PDF

### Автоматическая сборка через GitHub Actions

При отправке изменений в репозиторий (`push`) или создании pull request запускается workflow **Build PDF**. Также сборку можно запустить вручную на вкладке **Actions**.

Workflow использует Tectonic и собирает файл `article.tex`. Для сохранения соответствия шрифтовому оформлению шаблона используется Windows runner, в окружении которого доступен Times New Roman.

После успешного завершения сборки PDF-файл `article.pdf` публикуется как артефакт GitHub Actions:

1. Откройте вкладку **Actions** репозитория.
2. Выберите последний успешный запуск workflow **Build PDF**.
3. В блоке **Artifacts** скачайте `UWB-antennas-article-pdf`.

### Локальная сборка

Для локальной сборки необходим установленный [Tectonic](https://tectonic-typesetting.github.io/) и GNU Make.

Из корневой папки репозитория выполните:

```bash
make article
```

Готовый PDF будет создан по пути:

```text
build/article.pdf
```

То же самое можно выполнить без Make:

```bash
tectonic -o build article.tex
```

Для сборки через XeLaTeX можно выполнить команду дважды, чтобы LaTeX обновил ссылки и нумерацию:

```bash
xelatex article.tex
xelatex article.tex
```

В этом случае PDF будет создан в корневой папке репозитория.

## Редактирование статьи

Основной файл статьи — `article.tex`. В нём находятся название, сведения об авторах, аннотация, ключевые слова, текст разделов и список литературы.

Для добавления источника укажите библиографическую запись в окружении `thebibliography`, а в тексте статьи используйте команду `\cite{ключ_источника}`. Ключ в команде `\cite{...}` должен совпадать с ключом соответствующего элемента `\bibitem{...}`.

Файл `misisarticle.cls` определяет параметры оформления документа. Его следует хранить в корне репозитория рядом с `article.tex`.
